Git Commands Reference - Assignment 1

1. git init -b main
   Initializes a new local Git repository in the project folder with 'main' as the default branch.

2. git status
   Displays the current state of the working directory and staging area, including tracked, untracked, and ignored files.

3. git add <file>
   Stages changes in the specified file(s) so they are included in the next commit.

4. git commit -m "<message>"
   Records the staged snapshot permanently into the repository history with a descriptive commit message.

5. git branch feature
   Creates a new branch named 'feature' pointing to the current commit without switching to it.

6. git checkout feature / git checkout main
   Switches the active working branch to 'feature' or back to 'main'.

7. git merge feature --no-ff -m "<message>"
   Integrates commits from the 'feature' branch into 'main', creating a merge commit that preserves branch history.

8. git log --oneline --graph --all --decorate
   Displays a compact visual commit graph showing all branches, tags, and commit history.

9. git revert HEAD --no-edit
   Safely undoes the most recent commit by creating a new inverse commit, preserving full repository history.

10. git remote add origin <repository-url>
    Links the local Git repository to a remote repository on GitHub named 'origin'.

11. git push -u origin main
    Uploads all local commits and branches on 'main' to the remote GitHub repository and sets upstream tracking.
